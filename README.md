# Family Pop Quiz

A four-player trivia night game focused on **movies, TV shows, and pop culture**.

## Play

- Open `index.html` in a browser (great on a TV or passed-around phone/tablet).
- Enter the four players' names, pick a session length (40, 48, or 60 questions), and go.
- 100-question bank across movies, TV, music, and pop culture, randomized each game.
- 45-second pauseable timer per question, automatic turn rotation, answer reveals,
  full- and half-point scoring, steals, progress tracking, final rankings, and rematch.

## Session length

A full 60-question session comfortably fills an hour or more of play.

Built as a single self-contained HTML file — no build step, no dependencies.
